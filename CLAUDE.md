# Milestone 6 dashboard — notes for Claude

SvelteKit (Svelte 5 runes) + D3 mini-dashboard combining **Sketch 10** (bivariate county
choropleth) and **Sketch 19** (scatterplot: access change vs OB-GYN supply).

Question: *Where do greater increases in driving distance to abortion care overlap with
limited OB-GYN supply, and how are these counties distributed geographically?*

## Data

- `data/` is the team's original processed data. **Never edit or overwrite it.** The
  CSV is authoritative where `data/README.md` / `DATA_DICTIONARY.md` disagree (some README
  headline counts are stale, e.g. counties with increased distance, no-OB-GYN count,
  `hit_twice`; and `metro` is null for 9 rows although the docs imply full coverage).
- `static/data/` holds only runtime files, generated by `npm run data`
  (`scripts/prepare-data.mjs`), which also prints all data and join checks:
  - `counties.csv` — the 11 needed columns from `data/counties.csv`, values verbatim.
  - `counties-albers-10m.json` — us-atlas 3.0.1 (Census 2017 cartographic boundaries),
    **pre-projected** with geoAlbersUsa to 975×610 → use `d3.geoPath()` with no projection.

### Plotted variables (use this wording)
- **x / map dim 1:** `drive_miles_change` — change in road miles to the nearest open
  abortion clinic, May 2022 → July 2026 (= `drive_miles_jul2026 − drive_miles_may2022`,
  verified exactly). Positive = farther. Range −222.5 to 775.1.
- **y / map dim 2:** `obgyn_per_10k_women` — OB-GYNs per 10,000 women ages 15–44,
  **measured in 2023**. A single cross-section: do **not** call it a pre-Dobbs baseline and
  do not imply any change/decline in supply was measured. Range 0 to 77.57; 1,457 counties are 0.
- Context fields: `county`, `state`, `state_abbr`, `drive_miles_may2022`,
  `drive_miles_jul2026`, `ob_hospitals`, `women_15_44` (weight for any average), `metro`.

### Parsing / nulls / FIPS
- Parse with `parseCounty` in `src/lib/parse.js` (shared by app and script). **Never**
  `d3.autoType` the whole row.
- `fips` is always a 5-char zero-padded string; it is the join key to TopoJSON `feature.id`.
- Empty numeric cells → `null`, never 0. `metro` → `true` / `false` / `null`.
- Scatterplot includes a row iff `hasPlottedValues(d)` (both plotted values non-null) —
  regardless of whether a map shape exists.

### Known gaps (disclose in the UI)
- Missing plotted values (3 rows, Alaska): `02063` Chugach and `02066` Copper River have no
  distance; `02261` Valdez-Cordova has no OB-GYN/women data. → scatterplot has **3,140** rows.
- Geometry is 2017-vintage: it still has `02261` Valdez-Cordova and lacks its 2019
  successors `02063`/`02066`. These are **not** crosswalked. `02261` draws as "no data"
  (missing supply); Chugach/Copper River have no shape and no complete values.
- `11001` District of Columbia has a shape but no CSV row → "no data".
- Connecticut uses the 8 legacy counties (`09001`–`09015`) in both CSV and geometry → matches.
- All 3,140 scatterplot rows have a map shape.

## Svelte vs D3 responsibilities
- **Svelte** renders all marks (`<path>`, `<circle>`, `<rect>`), legends, tooltips, and
  holds state (`$state`, `$derived`) such as the selected/brushed set.
- **D3** computes: scales (`d3.scale*`), bivariate class thresholds, axes (via
  `d3.axis*` applied in an action/`$effect` on a `<g>`), `d3.geoPath()` strings, and later
  `d3.brush` (only emits extents; Svelte derives the selection).
- Keep D3 out of the DOM for data marks — no `selectAll().data().join()` for marks.

## Dashboard structure
- `src/routes/+page.svelte` — parent: owns shared data, classifies records once
  (`classify()`), computes counts, renders header/stats, details placeholder, methods note.
- `src/lib/components/Map.svelte` — county `<path>`s (keyed by `fips`), two-tone state
  lines, nation outline; missing = hatch pattern.
- `src/lib/components/Scatterplot.svelte` — one `<circle>` per county (keyed by `fips`),
  linear x / square-root y over the full range, 8 px inset, dashed refs at x=0/100, y=0/2.5;
  D3 axes via `$effect`.
- `src/lib/components/Legend.svelte` — 3×3 HTML legend with per-cell county counts.
- `src/lib/categories.js` — **single source** for thresholds, labels, `PALETTE[supply][dist]`,
  missing style. Categories are computed from `drive_miles_change` and
  `obgyn_per_10k_women`; never from `access_band` / `hit_twice` (different concept).
  Bins: distance ≤0 | >0–<100 | ≥100 mi; supply >2.5 | >0–2.5 | 0. Exploratory cut points.

## Interaction state (all in `+page.svelte`)
- `filter` ('all'|'metro'|'nonmetro'), `selection` ({mode:'none'|'county'|'category'|'brush', …criteria}),
  `hoverFips` (emphasis only), `plotMode` ('inspect'|'brush').
- `selected` (Set or null) is **derived** via `selectedFips(selection, eligible)` in
  `src/lib/selection.js`; never stored. Each new selection replaces the previous one.
- Components only call callbacks (`onhover`, `onselect`, `onbrush`); they never touch each other.
- Brush stores data-space extents (inverted through x/y). Programmatic `brush.move(null)` has no
  `sourceEvent` and is ignored, so clearing the visual brush can't erase a map/legend selection.
- y-scale is square root only (`src/lib/scales.js`: `makeYScale`, ticks in original units).
  Brush test uses `inBrush()` with a 1e-9 tolerance because invert(scale(v)) ≠ v exactly.
  `npm run verify` checks categories, filters, joins and brush inversion against the raw CSV.
- Filter change clears selection + brush; scatter domains come from all rows (fixed across filters).
- metro null (CT) → in 'all' only. Ineligible / missing-value shapes are not selectable.

## Paths / deploy
- Fetch static files with `asset('data/...')` from `$app/paths` (base-path aware).
- `adapter-static`; `+layout.js` sets `prerender = true`, `ssr = false`.
- Subdirectory build: `BASE_PATH=/repo-name npm run build` (read in `vite.config.js`;
  SvelteKit 3 config lives in the `sveltekit({...})` plugin options, no `svelte.config.js`).

- Deploy: GitHub Pages via `.github/workflows/deploy.yml` (push to `main`; Pages source =
  GitHub Actions). The workflow sets `BASE_PATH=/<repo-name>`. `static/.nojekyll` and
  `static/favicon.svg` (linked in `src/app.html` via `%sveltekit.assets%`) are copied to the build.
